# Como atualizar o repositório já publicado

## Arquivos para substituir

Envie novamente, mantendo os mesmos caminhos:

- `README.md`
- `CITATION.cff`
- `LICENSE`
- `requirements.txt`
- `data/README.md`
- `data/data_dictionary.md`
- `python/README.md`
- `python/visualizacoes.py`
- `sql/00_criacao_tabelas.sql`
- `sql/01_validacao_e_testes.sql`

## Arquivos novos

- `LICENSE-CODE`
- `docs/FONTES_E_METODOLOGIA.md`

## Arquivo antigo para apagar

- `docs/fontes_e_referencias.txt`

## Commit sugerido

Título:

`Corrige documentação, proveniência dos dados e reprodução do projeto`

Descrição:

`Atualiza README, citação, licenciamento, nota metodológica, validações SQL e script Python.`

## Apresentação

A pasta `presentation/` contém fotografia pessoal e imagens de terceiros. Ela pode permanecer pública, mas é recomendável removê-la do GitHub caso o objetivo seja manter apenas os materiais técnicos e acadêmicos do projeto.

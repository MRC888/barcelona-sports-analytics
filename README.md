# Consultas SQL

Ambiente de referência: PostgreSQL, com execução no DBeaver.

Ordem sugerida:

1. `00_criacao_tabelas.sql`
2. Importar os CSVs de `data/csv/` para as tabelas homônimas
3. `01_validacao_e_testes.sql`
4. Executar os blocos analíticos de `02` a `07`

As consultas cobrem validação, evolução do Barcelona, comparação com a Espanha, campeões vs rebaixados, cinco grandes ligas, respostas ao tiki-taka e Champions League.
